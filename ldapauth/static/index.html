              Download and install the authentication script
              
    
                Download the script, then copy it from your computer into the same Home Assistant
                folder as configuration.yaml using File editor or Studio Code Server. Name it
                auth-wrapper.py, without a .txt suffix. Core reads it as /config/auth-wrapper.py.
                Downloading alone does not install it. It contains a private API key; keep it out of
                shared folders and Git.
              
    
              Download auth-wrapper.py
            
    2. 
            
  2. 
              Add the authentication provider
              
    
                Merge this into configuration.yaml. Keep the local Home Assistant provider as a
                fallback.
              
    
              
    homeassistant:
  auth_providers:
    - type: command_line
      name: Active Directory
      command: /usr/local/bin/python3
      args:
        - /config/auth-wrapper.py
      meta: true
    - type: homeassistant
    
            
    3. 
            
  3. 
              Restart Home Assistant
              
    
                Keep your current administrator session open and test AD sign-in in a private
                browser window. Members of the allowed group get access.
